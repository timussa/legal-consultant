ОГРАНИЧЕНИЯ

Что мы честно не обещаем

Законы — только действующие

Старых редакций в базе нет, поэтому выводов на прошлые даты по законам ассистент не делает.

Проверка — не гарантия

Две проверки снижают риск ошибки, но юридическую ответственность за вывод несёт юрист.

Прототип, не прод

Вход по логину в SQLite, лимиты в памяти процесса. Для банка — SSO и общий счётчик.

Защита роли — правилами

Подмену роли сдерживают системные правила и фильтр строк-команд, а не отдельный классификатор.

Полный список — в README, раздел «Что ещё требует проверки»
Ограничения взяты из README команды. Персональные данные в базе тестовые, ключи моделей в репозиторий не попадают.
